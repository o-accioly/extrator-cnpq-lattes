# Regra — Memória

- A memória do projeto é a auto-memória do Claude (`MEMORY.md` + um arquivo por fato). Não usar o napkin.
- Salvar na hora quando o usuário corrigir o modo de trabalhar, decidir processo/escopo, revelar preferência ou apontar recurso externo.
- `MEMORY.md` só carrega até 25KB: uma linha curta por item (até ~120 caracteres), e item concluído vai para `ARCHIVE.md` em vez de ficar no índice.
